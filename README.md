# HackaSocial
Repo for app build

## Frontend

The `frontend` directory contains a Vite + React JavaScript app with hot module
replacement, a sample counter, styles, assets, and Oxlint configuration.

### Requirements

Install Node.js 24 LTS (including npm) before running the app in a new terminal.

### Development

```sh
cd frontend
npm install
npm run dev
```

Open the local URL printed by Vite. Start editing `frontend/src/App.jsx`.

### Checks and Production

Run these commands from `frontend`:

```sh
npm run lint
npm run build
npm run preview
```

The production build is written to `frontend/dist`.
